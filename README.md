## 📋 Команды

### Основные команды

| Команда | Описание |
|---------|----------|
| `/start` | Начать работу с ботом |
| `/help` | Показать справку по всем командам |
| `/profile` | Показать ваш профиль и настройки |
| `/cost` | Информация о подписке Gemini Pro |

### Настройка профиля

| Команда | Пример | Описание |
|---------|--------|----------|
| `/setage <возраст>` | `/setage 25` | Установить возраст |
| `/setheight <рост>` | `/setheight 175` | Установить рост (см) |
| `/setweight <вес>` | `/setweight 70` | Установить вес (кг) |

После указания всех параметров бот автоматически рассчитает:
- **BMR** (базальный метаболизм)
- **TDEE** (дневная норма калорий)
- **Целевые калории** (в зависимости от цели)
- **Целевые макросы** (Б/Ж/У)

### Отчеты и графики

| Команда | Описание |
|---------|----------|
| `/report` | Отчет за сегодня (приемы пищи, калории, КБЖУ) |
| `/graph` | График калорий и КБЖУ за неделю |

### История

| Команда | Пример | Описание |
|---------|--------|----------|
| `/history` | `/history` | Показать последние 5 приемов пищи |
| `/search <текст>` | `/search пицца` | Найти приемы пищи по названию блюда |

### AI-чат режим

| Команда | Описание |
|---------|----------|
| `/chat` | Включить режим чата с AI-нутрициологом |
| `/stopchat` | Выключить режим чата |

В режиме чата все ваши сообщения идут напрямую AI-нутрициологу. Бот помнит контекст разговора и ваши последние приемы пищи.

## 🚀 Установка и запуск

### Требования

- Docker и docker-compose (для запуска в контейнере)
- ИЛИ Python 3.11+ (для локального запуска)
- Telegram Bot Token
- Google Gemini Pro API Key

### 1. Получите API ключи

#### Gemini Pro API Key
1. Откройте: https://aistudio.google.com/app/apikey
2. Войдите с Google аккаунтом
3. Нажмите "Get API key" → "Create API key"
4. Скопируйте ключ

**Текущий ключ:** `AIzaSyD0GxPM4sihnh84nWWPKX1CWzEzvqiZnRI`

#### Telegram Bot Token
1. Откройте [@BotFather](https://t.me/botfather)
2. Отправьте `/newbot`
3. Следуйте инструкциям
4. Скопируйте токен

**Текущий токен:** `8179214743:AAF5nMEd7COJi07l1qegjq4mh77xcvRWf-0`

### 2. Клонируйте репозиторий

```bash
git clone https://github.com/amois3/nutrition_bot.git
cd nutrition_bot
```

### 3. Создайте .env файл

Файл `.env` должен содержать:

```env
# Telegram Bot Configuration
TELEGRAM_BOT_TOKEN=8179214743:AAF5nMEd7COJi07l1qegjq4mh77xcvRWf-0

# Gemini Configuration
GEMINI_API_KEY=AIzaSyD0GxPM4sihnh84nWWPKX1CWzEzvqiZnRI
GEMINI_MODEL_VISION=gemini-1.5-pro-latest
GEMINI_MODEL_TEXT=gemini-1.5-pro-latest

# MongoDB Configuration
MONGODB_URI=mongodb://mongodb:27017
MONGODB_DATABASE=nutrition_bot

# Bot Settings
BOT_LANGUAGE=ru
TIMEZONE=Europe/Moscow
LOG_LEVEL=INFO

# Reports Schedule (cron format)
DAILY_REPORT_TIME=21:00
WEEKLY_REPORT_DAY=monday
WEEKLY_REPORT_TIME=09:00

# Image Optimization
MAX_IMAGE_SIZE=2048
IMAGE_QUALITY=85

# Rate Limiting
RATE_LIMIT_MESSAGES=30
```

### 4. Запустите бота

#### С Docker (рекомендуется):

```bash
# Для старого docker-compose (с дефисом)
sudo docker-compose down
sudo docker-compose build --no-cache
sudo docker-compose up -d

# Для нового docker compose (без дефиса)
sudo docker compose down
sudo docker compose build --no-cache
sudo docker compose up -d

# Просмотр логов
sudo docker-compose logs -f --tail=50 bot
```

#### Локально:

```bash
# Установите зависимости
pip install -r requirements.txt

# Запустите MongoDB отдельно
# Или измените MONGODB_URI в .env на внешний MongoDB

# Запустите бота
python bot.py
```

### 5. Проверьте работу

В логах вы должны увидеть:
```
Using token: 8179214743...Wf-0
Bot starting...
```

Откройте бота в Telegram и отправьте `/start`
